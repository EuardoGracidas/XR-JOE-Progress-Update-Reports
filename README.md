## Summary

This GitHub project is for keeping a track into the projects developed by us as well as the decisions we take in our bi-weekely meetings. 

## Kanban board

1. Open the **Projects** tab at the top of this repository and click the board.
2. **Add a task:** click **+ Add item** at the bottom of a column and type the task.
3. **Move a task:** drag the card to another column (**Todo → In Progress → Done**).
4. **Assign a task:** open the card and pick a person under **Assignees**.

## Meeting notes

1. Open the `meetings` folder.
2. Click **Add file → Create new file**.
3. Name the file with the meeting date, e.g. `2026-11-05.md`.
4. Copy the template below, fill it in, and click **Commit changes**.

```markdown
# Meeting YYYY-MM-DD

**Attendees:**

## Discussed
-

## Decisions
-

## Next steps
- [ ] Task — Person
```
